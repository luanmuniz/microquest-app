# Microquest Roadmap (User View)

This roadmap focuses only on user-facing improvements: UI polish, usability, and features that make Microquest more valuable for people using it on the web.

## Phase 1: Launch Essentials (Highest Impact)

1. Home dashboard
Create a simple landing screen after login/open with Today's Quest, streak, recent wins, and quick actions. This helps users understand what to do next in one glance.

2. Better Today flow
Add a clear state system for each day: Not started, In progress, Completed. This makes progress feel tangible and removes ambiguity.

3. Search, filter, and sort
Let users search quests and history, then filter by status/date and sort by newest, oldest, or priority. This becomes critical as data grows.

4. Undo actions
Add Undo in toast messages for destructive or easy-to-misclick actions like delete and complete. This reduces user anxiety and mistakes.

5. Mobile-first navigation polish
Improve tap targets, spacing, and compact menu behavior for smaller screens. A smoother phone experience is key for public adoption.

## Phase 2: Habit-Building Features

6. Quest templates
Offer starter templates (Fitness, Study, Mindfulness, Work, Health) so users can begin without decision fatigue.

7. Recurring quests
Support repeating schedules (daily, weekdays, custom days). This aligns with how habits actually work.

8. Reminder system
Allow optional reminder times with browser notifications. Timely reminders increase completion rates.

9. Streaks and progress views
Show streaks, weekly summaries, and a calendar or heatmap view. Visual progress boosts motivation and retention.

10. Milestones and badges
Add lightweight achievements like first 7-day streak or 50 completions. Recognition reinforces consistency.

11. Pin or favorite quests
Let users pin important quests to keep them visible at the top. This improves focus for users with many quests.

## Phase 3: History and Reflection Improvements

12. Richer history controls
Allow editing or deleting completion entries and reflections. Users should be able to correct mistakes and keep history accurate.

13. Better empty states
Improve empty screens with examples and one-click next actions. This helps new users understand the path forward instantly.

14. Personalized onboarding
Ask users what they want to improve first (health, study, productivity, etc.) and suggest relevant starter quests.

15. Reflection prompts
Provide optional reflection prompts (What helped today? What was hard?) to make journaling easier and more useful.

## Phase 4: Personalization and Trust

16. Theme and visual personalization
Add an in-app theme toggle and optional accent palettes. Personal control over look-and-feel increases delight.

17. Data center UX
Create a dedicated settings/data page with clear messaging about local storage, plus import/export and reset controls.

18. Feedback button
Add a visible "Suggest a feature" / "Report a problem" entry point. This creates a direct feedback loop with early users.

19. Shareable progress cards
Generate simple weekly summary cards users can share. This encourages accountability and organic growth.

## Suggested Build Order

1. Dashboard, Today flow, Search/Filter/Sort, Undo, Mobile polish
2. Recurring quests, reminders, streaks, templates
3. History editing, onboarding personalization, reflection prompts
4. Themes, data center UX, feedback, share cards

## Success Metrics (User-Centered)

1. Activation: percent of users who create at least 1 quest on first session
2. Engagement: percent of users who set Today's Quest at least 3 times per week
3. Retention: day-7 and day-30 return rate
4. Completion quality: percent of completions with reflection text
5. Usability: reduction in accidental delete/complete actions after Undo
